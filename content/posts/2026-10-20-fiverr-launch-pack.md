# Fiverr Launch Pack

Everything copy-paste ready for a new Fiverr seller account. Follow the steps in order.

---

## 1. Account setup checklist

1. fiverr.com → **Join** → Continue with Google (or email) → pick username
2. Profile photo: clear, front-facing, simple background (same one as LinkedIn for consistency)
3. Profile picture menu → **Become a Seller** → watch the 3 onboarding videos
4. Fill in the freelancer profile:
   - Option A: upload your LinkedIn profile PDF and edit what it fills in
   - Option B: add manually using the bio in section 2 below
5. Phone verification (required before publishing)
6. Create the gig on **desktop**: My Business → Gigs → Create a New Gig

## 3. First gig (publish this one)

### Overview

- **Title:** `I will build a custom AI agent or automation for your business`
- **Category:** Programming & Tech → (AI Agents or Bot Development subcategory)
- **Search tags:** `ai agent`, `automation`, `chatbot`, `workflow automation`, `openai`
- **Service description words:** ai agent, automation, chatbot, integration

### Packages

| | Basic | Standard | Premium |
|---|---|---|---|
| Name | Starter Agent | Business Agent | Agent System |
| Price | $75 | $200 | $450 |
| Delivery | 3 days | 5 days | 7 days |
| Revisions | 1 | 2 | 3 |
| Includes | One AI agent or one workflow automation, single task, 1 integration | Multi-step agent, 2 integrations, basic error handling | Full agent setup, 3+ integrations, documentation, 14 days of post-delivery support |

**Gig extras:**

- Extra fast delivery: +$50 (Basic), +$100 (Standard)
- Source code handover with comments: +$50
- 30 days of support and fixes: +$75
- Recorded walkthrough video of the system: +$40

### Description (fits the 1,200 character limit)

> Your team is losing hours to repetitive work. I build AI agents and automations that take it off their plate.
>
> What I can build for you:
> - An AI agent that answers customer or internal questions from your own documents and data
> - An automation that moves information between your tools (CRM, sheets, Slack, email) with no manual copying
> - A lead qualifier that sorts inbound enquiries before you ever read them
> - A custom chatbot for your website or WhatsApp
>
> How it works:
> 1. You tell me the task in plain English
> 2. I confirm scope and deliver a plan before building
> 3. I build, test, and hand it over working
>
> You get clean, documented code you own. No lock-in, no monthly fee to me.
>
> Not sure what you need? Message me before ordering. I will tell you honestly whether this is a fit.

### Requirements (client must answer before work starts)

1. `What task should the agent or automation do? Describe it in plain English.` (required)
2. `Which tools or apps are involved? (e.g. Slack, Google Sheets, HubSpot, WhatsApp)` (required)
3. `Do you already have API keys or accounts for those tools, and who can grant access?` (required)
4. `What does a successful result look like for you?` 
5. `Is there an example or sample of the input the system will receive?`

### FAQ

1. **Do I need any technical knowledge to use what you build?**  
   No. I hand over a system that runs on its own, plus a short recorded walkthrough so anyone on your team can operate it.

2. **Do I need API keys or paid accounts?**  
   Some tools require a paid plan or API key (for example OpenAI). I will tell you exactly what is needed before I start, and it is paid directly to the provider, never to me.

3. **Do I own the code?**  
   Yes. Source code handover is available as an add-on, and everything I build runs on accounts you control.

4. **What if the agent makes mistakes?**  
   I build in error handling and testing against real examples you provide. Every package includes revisions so we tune it until it behaves correctly.

5. **Can you work with tools not listed here?**  
   Probably. Message me with the tool name and I will confirm within a few hours.

6. **What is not included?**  
   I do not build mobile apps, full websites, or anything that violates Fiverr's terms. Automation and AI agent work only.

## 5. After publishing

- New gigs get a visibility boost in their first weeks. Keep the account active and reply to messages within hours.
- Share the gig link on LinkedIn and in your newsletter (the badge embed also works on your site).
- First 2–3 orders: price is already competitive, deliver early, ask for a review politely in the handover message.
- New sellers can have up to 4 active gigs.
- You keep 80% of each order.
